## 📌 Project Overview

As a **Student Digital Ambassador** at VIT Bhopal University, this portfolio documents my journey through five core modules of Digital Literacy. The project covers infographic design, building a professional digital presence, exploring coding and collaboration platforms, mastering professional email communication, and understanding cybercrime awareness.

All tasks are organized in this GitHub repository as part of the final submission for CSE0001.

## 📝 Module Summaries

### ✅ Task 1 – Digital Literacy Awareness Infographic
Created a one-page infographic using **Canva** covering what digital literacy means, safe internet practices, and professional online presence. The design was exported and added to `task-1-presentation/`.

### ✅ Task 2 – Student Digital Portfolio
Set up professional profiles on **GitHub**, **LinkedIn**, and **Kaggle**. Each platform serves a unique purpose in building a long-term digital identity for academic and professional growth.

### ✅ Task 3 – Coding & Collaboration Platforms
Completed a beginner coding challenge on **HackerRank** and created a **Google Form** Digital Literacy Awareness Quiz with 5 questions for batchmates.

### ✅ Task 4 – Professional Email & Etiquette Guide
